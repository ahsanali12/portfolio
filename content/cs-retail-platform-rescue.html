The situation

The company ran its e-commerce site, in-house CRM and marketing tools on an outdated PHP framework, with old PHP and MySQL versions and years of messy legacy code. Pages and queries were slow. Heavy processes took the server down during traffic spikes. The server bill kept rising, and so did customer complaints and drop-offs. There was no proper release process.

What I did

  1. Modernized without stopping sales. I upgraded the framework, PHP and MySQL in stages, cleaned up the code and normalized the database.
  2. Made it fast under load. I optimized the slowest queries, moved heavy work into background jobs, and improved the infrastructure.
  3. Built an engineering system. I introduced a Git workflow, a CI/CD pipeline and code review, so the team could ship safely and often.
  4. Added revenue features. Abandoned-cart recovery, discounts and loyalty points.
  5. Hardened it. Security improvements against attacks, plus SEO fixes across the site and CRM.

Results

  • check_circle~60% faster load times
  • check_circle~$6,000/month lower server costs (about $72k a year)
  • check_circleStable for ~1M users, with no more downtime during traffic spikes
  • check_circleMore revenue and repeat customers from the cart, discount and loyalty features
  • check_circleFewer complaints and drop-offs, and a codebase that's easy to change
